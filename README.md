# CadetTest

Bu projede, ASP.NET Core Web API üzerinden onay kayıtlarının listelenmesi ve yönetilmesi için çalışmalar yaptım.

### Yaptıklarım

- API üzerinden onay kayıtlarını 10'ar 10'ar çektim ve HTML tablosunda görüntüledim.
- Her 10 kayıtlık grubun ardından Recipient sütununda güncel saati gösteren bir satır ekledim.
- Yeni kayıt ekleme, mevcut kaydı güncelleme ve kayıt silme işlemlerini API ile entegre ettim.
- CRUD işlemlerinden sonra sayfanın yeniden yüklenmesine gerek kalmadan ilgili tablo satırının dinamik olarak güncellenmesini sağladım.
- JWT token ile kimlik doğrulama ve yetkilendirme işlemlerini kullandım.
- Backend tarafında veri işlemleri için Entity Framework Core ve LINQ kullandım.

### Kullanılan Teknolojiler

- C#
- ASP.NET Core Web API
- Entity Framework Core
- LINQ
- JWT
- HTML
- CSS
- JavaScript
